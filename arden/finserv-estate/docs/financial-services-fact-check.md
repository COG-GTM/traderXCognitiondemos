## 4. Materially better information from the last 90 days (added)

1. **Artifactory three-CVE chain + backdoors** (Wiz, 11–14 Sep 2026) — see row 1b. Turns Demo 1 from "one patch" into "fleet exposure to a product that has shipped three auth bugs since July".
2. **Fastly's remediation guidance** ("patch does not revoke tokens already minted; revoke tokens issued since 28 Aug; HTTP 201 on join = compromise") — gives Demo 1's remediation report a real, sourced checklist beyond the version bump.
3. **Second Revolut incident (DriveWealth, reported 24–25 Sep)** — the fact base predates it; it is the freshest third-party-blast-radius example available.
4. **Hilltop restoration 22 Sep** — closes the story: 14 days, weekend batch backlog processing.
5. **T+1 plan's "~20% of processing time"** figure — better quantifier for Demo 2's "removal of the overnight window".
6. **SEC deregulatory push (Sep 2026)** — not a change in law, but AEs should expect a CISO to ask "isn't 1.05 going away?" Answer: pending petition, no proposal.
