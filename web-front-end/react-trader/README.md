# TraderX Web Front End (React)

React + TypeScript migration of the Angular trade blotter app in `web-front-end/angular`, built with Vite, React Router, and `ag-grid-react`.

## Scripts

- `npm start` / `npm run dev` — dev server on port `${WEB_SERVICE_PORT:-18094}`
- `npm run build` — typecheck and production build
- `npm test` — run Vitest + React Testing Library suite

Backend service URLs mirror the Angular app's `environments/environment.ts`.
